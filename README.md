# 📊 Social Media Marketing Analytics

An interactive data analytics project built using **Microsoft Power BI** to analyze Instagram performance and marketing campaign effectiveness.

## 📌 Project Overview

This project includes two interactive dashboards designed to explore social media engagement and marketing campaign performance through key performance indicators (KPIs), charts, and filters.

## 📈 Dashboard 1: Social Media Analytics

* Total Posts
* Total Likes
* Total Comments
* Total Shares
* Average Engagement Rate
* Interactive filters for dates, media types, and content categories

## 📢 Dashboard 2: Marketing Campaign Analytics

* Total Campaigns
* Total Impressions
* Total Clicks
* Average ROI
* Average Conversion Rate
* Campaign performance by type and marketing channel
* Impressions and clicks over time

## 🛠️ Tools & Technologies

* Microsoft Power BI
* Power Query
* DAX (Data Analysis Expressions)
* Data Visualization
* KPI Analysis

## 🎯 Project Objectives

* Analyze Instagram content performance and audience engagement.
* Evaluate marketing campaign effectiveness.
* Compare performance across campaign types and channels.
* Present data through interactive dashboards.

## 🚀 How to Use

1. Download the `.pbix` file from this repository.
2. Open it using Microsoft Power BI Desktop.
3. Explore both dashboard pages.
4. Use the filters to analyze different dates, categories, and channels.
